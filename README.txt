FURY FISTS - online server + Android app (one project)

www/index.html   the game
www/config.js    put your server address here (one line) after you deploy
server.js        the online server (rooms + relay)
package.json     lists what the server and the app builder need
.github/workflows/build-apk.yml   builds the Android APK automatically on GitHub
